# Changelog

All notable changes to this project should be documented here.

This project currently has no tagged public releases.

## Unreleased

- Native macOS SwiftUI camera viewer.
- Local camera discovery with ONVIF, Bonjour, SSDP/UPnP, known-host probing, and bounded port scans.
- Camera metadata persistence in Application Support.
- Camera password storage in macOS Keychain.
- HTTP, MJPEG, HLS, and ffmpeg-backed RTSP playback.
- Stream quality and encoder mode controls.
- Saved multi-camera views with configurable layout.
- AirPlay-capable composite view casting through ffmpeg.
- PTZ controls for compatible cameras.
- Public repository documentation, contribution guidelines, security policy, and issue templates.

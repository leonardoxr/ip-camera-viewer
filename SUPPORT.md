# Support

Use GitHub issues for bugs, feature requests, and documentation improvements.

Before opening an issue:

- Check [README.md](README.md) and [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
- Try the latest `main` branch if you can build locally.
- Remove passwords, credential-bearing stream URLs, private IPs, hostnames, and private-space screenshots from reports.

For security vulnerabilities, do not open a public issue. Follow [SECURITY.md](SECURITY.md).
